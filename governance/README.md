# Governance and Community Policies

This directory contains governance process documents for Open Engineering Education (OEE). The community membership policies ([CONTRIBUTING](../CONTRIBUTING.md), [Code of Conduct](../CODE_OF_CONDUCT.md), and [DCO](../DCO.md)) live at the repository root, where GitHub's community standards detection expects them.

## Documents

| Document | Purpose |
| --- | --- |
| [Governance](GOVERNANCE.md) | Defines stewardship and the decision-making process |

## How the policies work together

Contributors should read these policies before submitting work.

Routine corrections may proceed through a pull request. Changes to normative requirements or governance policy follow the Request for Comments (RFC) process in [`../rfcs/`](../rfcs/README.md).

Contributions must comply with the repository's declared licenses and retain the attribution required by those licenses. A DCO sign-off confirms the contributor's right to submit the contribution; it does not transfer copyright to the steward.

## Policy changes

A change that materially affects contributor obligations, stewardship authority, or decision-making MUST follow the RFC process.

A policy change is not effective merely because it has been proposed or discussed. The decision and resulting repository update must be recorded.
