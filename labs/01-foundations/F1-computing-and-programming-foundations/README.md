# F1-computing-and-programming-foundations lab log

Create one numbered subdirectory per experiment, for example `01-memory-mountain/`. Each experiment must answer one concrete question.

## Experiment template

```markdown
# <experiment name>

## Question

What mechanism or hypothesis is this experiment testing?

## Setup

Host/OS, CPU/GPU, memory, tool versions, dependencies, and input data.

## Procedure

Exact commands and inputs needed to reproduce the work.

## Results

Measurements, plots, test output, and raw-data location.

## Interpretation

What happened, why, limitations, and the next experiment.
```
