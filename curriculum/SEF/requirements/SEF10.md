# SEF10 — Required practical work and evaluation

> Public draft requirements preserved from the source. Independent learners can use these without a 0xNAND subscription. Detailed lab procedures and verification fields still require conformance review.

## Required qualities

The project must include:

- Clear requirements
- Modular architecture
- Git history
- Automated tests
- Input validation
- Error handling
- Documentation
- Reproducible setup
- CI
- Basic performance measurements
- Release/package instructions
- Architecture diagram
- Decision records
- Technical retrospective

## Project defense

The learner demonstrates the application live and explains:

- Architecture
- Data structures
- Important design decisions
- Failures encountered
- Testing strategy
- One measured improvement

This is the **Program 1 graduation requirement**.
