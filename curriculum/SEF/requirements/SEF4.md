# SEF4 — Required practical work and evaluation

> Public draft requirements preserved from the source. Independent learners can use these without a 0xNAND subscription. Detailed lab procedures and verification fields still require conformance review.

## Small exercises

- Implementation drills
- Tracing exercises
- Complexity analysis
- Recursive-call tracing
- Algorithm comparison

## Practical exercises

- Implement a stack and queue.
- Compare linear search and binary search.
- Implement BFS and DFS.
- Measure sorting algorithms on increasingly large inputs.

## Course lab

### Algorithm Toolkit

Implement and test:

- Stack
- Queue
- Linked list
- BST
- BFS
- DFS
- Binary search
- Merge sort
- Quicksort

Then benchmark selected operations and explain the results.

## Exit check

Given a new problem, the learner must:

- Choose an appropriate data structure
- Propose an algorithm
- Derive its complexity
- Explain why an obvious alternative approach is less suitable
