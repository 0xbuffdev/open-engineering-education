# Public SEF practical requirements

These are the **required exercises, integration labs, evaluation and exit criteria** that accompany the draft SEF curriculum. They are freely available and do not depend on 0xNAND, a book purchase, or a commercial learning platform. The imported instructions still require a separate OEE conformance review for complete lab environment and verification details.
