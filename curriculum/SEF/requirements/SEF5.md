# SEF5 — Required practical work and evaluation

> Public draft requirements preserved from the source. Independent learners can use these without a 0xNAND subscription. Detailed lab procedures and verification fields still require conformance review.

## Practical exercises

- Resolve a controlled merge conflict.
- Debug a deliberately broken application.
- Turn untested code into tested code.
- Refactor duplicated code without changing behavior.
- Review another learner's pull request.

## Course lab

### Tested CLI Application

Convert the SEF2 application into a maintainable software project with:

- Meaningful Git history
- Automated tests
- Linting/formatting
- Structured logging
- Error handling
- Refactored modules
- CI test execution
- Documentation

## Exit check

The learner must diagnose a failing test or bug from evidence rather than by guesswork.
