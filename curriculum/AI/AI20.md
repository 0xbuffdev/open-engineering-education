## Overview

**AI20 develops meaningful representations of connected entities and relationships, without confusing graph association, graph traversal, knowledge assertion and causal explanation.** Graduates independently model lawful and time-bounded nodes/edges, reason about adjacency/spectral/random-walk structure, derive permutation-correct message passing, train and compare genuine local GCN, GraphSAGE and graph-attention mechanisms, and evaluate node, link and graph tasks with rigorously controlled source, label, edge and time exposure. They can identify simple expressivity limits, oversmoothing, oversquashing and heterophily failure; handle typed relations and knowledge-graph candidates; inspect causal temporal cutoffs and neighbor sampling; and reproduce one small legitimate model-based graph study with independently defensible unknown-case behavior. A graph plot, successful graph traversal, learned edge score or explanatory-looking attention map **does not** establish an actual hidden relationship, logical truth, valid intervention cause or permission to reveal a connection.

**Foundations, applications and ownership.** Graphs model entities connected by observed or asserted relationships: social or collaboration networks, molecular bonds, citation/knowledge graphs, software dependencies, transaction networks, recommendations and timed events. Classical topology, matrices and random-walk methods quantify structure; node2vec/DeepWalk-style objectives embed contexts, while GCN, GraphSAGE, graph attention and general message-passing neural networks learn from features, edge structure and label evidence. Heterogeneous and temporal systems add relation and time constraints, and many link benchmarks illustrate how accidentally revealing a target edge can inflate model quality. A strong node classifier may still fail on a new graph; a good triple ranking score is neither truth nor license to expose that association. Graph learning is an **optional advanced AI specialty**, not a substitute for database querying, graph search, causal inference, identity verification or legal permission.

**Actual preparation and academic boundaries.** The **only direct prerequisite is completed [AI5](AI5.md)**, which provides differentiable representations, neural training, optimization and evaluation, and inherits [AI4](AI4.md) scientific learning, [AI2](AI2.md) probability/linear algebra and [AI1](AI1.md) data work. This elective explicitly teaches graph definitions, adjacency/spectral methods, random-walk embeddings, relation schemas, neighbor sampling and graph-specific evaluation before applying deep learning; hence a separate completed [AI3](AI3.md) graph search/logic course is **not** secretly required. AI3 already teaches finite state search and Bayesian graphical inference but **not** graph representation learning; the planned AI20 mechanism cannot be passed by merely running Dijkstra or interpreting a Bayesian DAG. [AI19](AI19.md) causal inference owns intervention identification, whereas AI20 uses observational relationship structure for predictive tasks and **does not infer causal effects** from graph attention or embeddings. [AI8](AI8.md) general image/vision representation, [AI13](AI13.md) system TEVV and [AI11](AI11.md) text RAG are complementary but **not separate compulsory prerequisites**. No optional AI17–AI19 course, APP/SYS/SEC program, paid graph database, proprietary graph provider, GPU, social-network scrape or real sensitive relationship data is assumed. **AI20 is not required for AI16 or core AI graduation.**

**Open, legitimate compulsory evidence.** Every required inference and genuine small learned model runs on an ordinary CPU using inspected/synthetic finite graph examples and optional properly licensed small graph datasets. Python/NumPy/PyTorch, TypeScript, Rust, R or equivalent open, reviewable tools may be used. PyTorch Geometric, DGL, OGB and NetworkX are useful **optional** libraries, not required output vendors; manual finite message passing is sufficient for exact derivations. The learner must actually train/evaluate a graph-dependent model where the claim depends on learned behavior: numerical oracles alone are not a substitute. Synthetic actor–relationship data allow safe privacy and link inference tests without disclosing real people's network associations. If an actual benchmark is selected, verify its individual data license, split and benchmark reporting protocol (including transductive observation rules or scaffold/temporal grouping), not a blanket assumption of unrestricted open content. All graph figures, path visualizations and training results must have accessible tables/numerical counterparts.

**Research and versioned technical guidance.** [Stanford CS224W Machine Learning with Graphs](https://web.stanford.edu/class/cs224w/) establishes the discipline's graph statistics, network embeddings, GNN architectures, heterogeneous structures and applications. The original [GCN](https://arxiv.org/abs/1609.02907), [GraphSAGE](https://arxiv.org/abs/1706.02216), [Graph Attention Networks](https://arxiv.org/abs/1710.10903), [Graph Isomorphism Network and 1-WL limits](https://arxiv.org/abs/1810.00826), [node2vec](https://arxiv.org/abs/1607.00653), [R-GCN](https://arxiv.org/abs/1703.06103), [Temporal Graph Networks](https://arxiv.org/abs/2006.10637) and [Beyond Homophily](https://arxiv.org/abs/2006.11468) form the method boundaries. [Open Graph Benchmark](https://ogb.stanford.edu/) defines realistic benchmark datasets/splits and task-specific evaluators; [PyTorch Geometric neighbor loader](https://pytorch-geometric.readthedocs.io/en/latest/tutorial/neighbor_loader.html) shows version-specific sampling behavior and pitfalls. These sources inform the **public assessment evidence**, not a list of proprietary mandatory readings; evaluation protocols and public software APIs evolve and must be version-pinned. A library's graph scores, attention plots or leaderboard never independently validate graph rights or train/test causality.

**How competency produces structure.** The essential dependency is **legitimate entities/graph scope → exact topology/matrices/walks → valid message-passing mechanisms → real node embedding and training → held-out link/graph tasks → limits of expressivity/heterophily → typed relation knowledge → causal *time*-aware sampling → one independently reproduced system and unfamiliar defense**. Individual lesson and module boundaries follow what learners must predict, compute, implement and diagnose, rather than a preset number of modules/lessons or a uniform test/lab sequence. The cumulative assessments share one real graph study and proportionate exact/oracle/typed/temporal diagnostic cases, not eight unrelated hosted products. The **19–27-week** estimate is provisional and includes genuinely coding GNNs, verifying graph splits/negative sampling, observing failures, CPU measurement and defense; it does not establish learner-tested readiness.

## Completion requirements

### Independent finite graph and learned-representation reference cases

All cases below state exact graph, edge, time, normalization, source and distribution conventions. Correct arithmetic is not evidence of observed model generalization; the assessments additionally require **executed CPU-local graph model inference/training**, observed baseline behavior and ethical source boundaries. No derived edge score authenticates or licenses a relationship.

**G1 — Structure, source semantics and degree convention.** An **undirected, simple, unweighted** graph on nodes **1,2,3,4** has edges **{(1,2),(2,3),(3,1),(3,4)}**, with no original self loops and each unordered edge listed only once. Its node degrees in ID order are **[2,2,3,1]**, and the degree sum **8 = 2×4 edges**. It is connected, with edge (3,4) a bridge. Self-loop addition for GCN normalization is a later **model operator**, not an assertion that a source relationship existed. A repeated transaction or bidirectional source record may instead require an explicitly defined multigraph or directed schema.

**RW1 — Short exact random walk.** On the **three-node undirected path 1–2–3**, the row-stochastic uniform-neighbor transition matrix is `P=[[0,1,0],[.5,0,.5],[0,1,0]]` under node order1,2,3. Starting at node1, the one-step distribution is **[0,1,0]** and the two-step distribution is **[.5,0,.5]**. The walk is periodic; it must not be described as necessarily converged to a stationary distribution in two steps. Other degree-zero or lazy-walk policies change the transition operator and expected result.

**SP1 — A spectral operator is not a canonical graph ID.** On the path 1–2–3, its unnormalized combinatorial Laplacian is `L=D−A=[[1,−1,0],[−1,2,−1],[0,−1,1]]`. `v=[1,0,−1]` obeys `Lv=v` (**eigenvalue1**) and `c=[1,1,1]` obeys `Lc=0` (**eigenvalue0**). Multiplying an eigenvector by −1 does not change its eigenspace; a repeated eigenvalue can permit arbitrary orthogonal basis rotation. Without sign/basis or structural alignment, a model that relies on one spectral vector's raw sign may spuriously change after an equivalent graph representation.

**N1 — Self-loop-normalized GCN step.** A two-node undirected graph has a single edge1–2 and no original self loops. Construct `Atilde=A+I=[[1,1],[1,1]]`, `Dtilde=diag(2,2)` and symmetrically normalized `Dtilde^(−1/2) Atilde Dtilde^(−1/2)=[[.5,.5],[.5,.5]]`. With scalar node features `X=[2,4]`, identity scalar weight1, no bias/nonlinearity, one propagation yields **[3,3]**. A directed adjacency, mean-only neighbor update without self, differently weighted loop or altered feature shape need not produce this answer.

**S1 — Directed GraphSAGE-style neighborhood aggregation.** Target node **2** has scalar own feature **x2=2** and **two incoming neighbors** nodes1 and3 with features **x1=1**, **x3=5**. Under an explicitly uniform neighbor mean with no duplicate edges, the neighbor value is **(1+5)/2=3**. Concatenate central then neighbor to `[2,3]`; a fixed row vector `W=[1,2]` without bias/normalization/activation produces **2+2×3=8**. Sum aggregation instead would give neighbor value6 and change the result; an outgoing-only directed edge list cannot silently be treated as incoming evidence.

**A1 — Two-neighbor graph-masked attention.** Two *permitted incoming neighbors* have attention logits **[0,ln3]**; their normalized softmax weights are **[1/4,3/4]**. For corresponding scalar message values **[2,6]**, the weighted result is **(1/4)×2+(3/4)×6=5**. These are conditional model weights under a fixed mask and feature state, not causal attributions or valid explanations of who influenced a real user. An isolated node needs explicit self/fallback policy and must not softmax over an empty neighbor set without handling it.

**LP1 — A withheld target must stay withheld from propagation.** The permitted **visible message graph** on nodes1,2,3,4 contains only undirected edges **(1,2),(2,3)** and isolated node4. The candidate future/held-out link **(1,3)** is **not** in the visible graph. Its common-neighbors score is **1** (shared node2); candidate **(1,4)** has common-neighbors score **0**. Whether an absent candidate is *truly negative* requires an independently defined observation/coverage protocol; missing links are often **unknown**, not false. Computing embeddings on a graph that secretly includes the target edge may leak the answer.

**P1 — Invariant graph-level readout depends on task.** Graph A has scalar node embeddings `[1,2,3]`, graph B has `[1,2,3,4]`. The **sum** readout gives **6** and **10**; **mean** readout gives **2** and **2.5**, respectively. Either readout is invariant to node ordering, but neither alone is universally appropriate: one captures count-sensitive information, the other often removes some graph-size influence. All source groups and whole-graph labels must remain properly isolated between fit and held-out evaluation.

**WL1 — A real expressivity boundary.** The six-vertex cycle **C6** and the disjoint union of **two triangles** both have **six vertices each of degree2**. With the **same constant initial node feature/color** on every vertex and the standard **one-dimensional Weisfeiler–Lehman color refinement**, every vertex in both graphs receives the same color at each iteration, and their graph-level color multisets remain indistinguishable, although one graph is connected and the other is not. Ordinary local message passing with identical initial features and permutation-invariant aggregation has the same limitation under the corresponding model restrictions; providing externally valid component/positional features can change the information available. It is not a proof that *all* graph encoders or architectures have equal expressive power.

**H1 — Heterophily is task- and edge-defined.** An undirected **four-cycle** with alternating class labels `[A,B,A,B]` on cyclic nodes has **4 of 4** edges connecting *different* labels. Under edge homophily defined as same-label edges divided by all four undirected edges, **homophily=0**. Copying a neighbor label is systematically wrong under this fixture; a model leveraging another feature, direction, even-hop context or a different task may nevertheless succeed. Heterophily is not a universal verdict against every GNN or evidence of a social person's characteristics.

**R1 — Typed relation-specific message passing.** A target node t has scalar feature **1**, self weight **1**. Incoming relation type r1 has neighbor features **[2,4]**, per-relation **mean** and weight **2**, contributing **6**. Relation r2 has one incoming neighbor feature **5**, weight **−1**, contributing **−5**. With a simple linear R-GCN-style update and no other relation/activation terms, target result is **1+6−5=2**. Aggregating r1/r2 together first, reversing incoming direction or treating an asserted triple as an authenticated fact violates the specified relationship model.

**T1 — Graph histories stop at the scoring cutoff.** Three fabricated edge-creation events are **(1,2,t=2), (2,3,t=4), (1,3,t=7)**; all times share a stated clock. At prediction cutoff **t=5** and with *strictly earlier* observed events available, the graph contains **(1,2),(2,3)** only. A t7 link may become the later **target label**, but is not a feature, adjacency edge, neighbor sample or model-memory update available at t5. An event arriving late can have observation time different from its physical creation time; evaluation must state which clock the learner legitimately knows.

**F1 — Neighbor fanout is a workload bound, not unique-node count.** Starting with **one seed node** and selecting at most **two neighbors** of each newly expanded node for **three** recursive neighborhood layers, the maximum sampled node **occurrences** including seed is **1+2+4+8=15**. Repeated vertex IDs, degree limits, replacement, and induced-edge policies change the distinct node/edge count and memory footprint; the actual CPU cost must be measured. This calculation is not a promise about scalability, unbiased gradients, exact full-batch equivalence or accelerator memory.

**Rights, evidence and safe refusal.** A graph can encode sensitive interpersonal ties, contact tracing, organizational dependencies or reputational inferences. A high-scored missing link or attention coefficient may be wrong, private, temporally obsolete or unauthorized; neither an embedding nor absence in a graph database verifies the true external relationship. A leak of a held-out edge, mislabeled source ID, stale event, forbidden graph join or revoked access should lead to **HOLD/UNKNOWN/RESTRICT** according to the lawful task contract, not a fabricated completion or factual assertion. An appropriate non-graph or no-use option remains valid when the structure is insufficient, wrongfully sourced, misleading or unnecessary.
