# F0-foundation-setup exercises

Put one file or subdirectory per exercise here. Each programming exercise needs tests for normal, boundary, and invalid cases. Each written exercise needs your reasoning, not only a final answer.

- [ ] Problem restated in my own words.
- [ ] Solution or implementation complete.
- [ ] Tests or worked cases recorded.
- [ ] Complexity and trade-offs recorded where relevant.
- [ ] One mistake, failed attempt, or correction recorded.
