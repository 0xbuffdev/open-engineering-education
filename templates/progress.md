## Completion rules

A course is complete only when all of these are true:

- [ ] Every required reading section is covered, with notes in `notes/<track>/<CODE>/`.
- [ ] Every required lab and exercise has an artifact.
- [ ] The project increment is integrated and tested.
- [ ] The exit check is demonstrated without notes.
- [ ] `notes/<track>/<CODE>/summary.md` links to the evidence.
- [ ] One failure or misconception is written up.
- [ ] The work is committed.

A project is complete only when:

- [ ] Its gate was passed before it started.
- [ ] The MVP works from a clean checkout.
- [ ] Tests cover normal, boundary, invalid, and failure cases.
- [ ] The evaluation or threat-model evidence is reproducible.
- [ ] The README states limitations and non-goals.
- [ ] The retrospective names one significant correction.
- [ ] No secrets, private data, weights, or copyrighted books are committed.
