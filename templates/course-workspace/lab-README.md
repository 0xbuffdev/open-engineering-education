# <course> lab log

**Course:** [<course>](<course_link>)

Create one numbered subdirectory per experiment, for example `01-memory-mountain/`. Each experiment must answer one concrete question and leave a reproducible artifact.

## Experiment template

```markdown
# <experiment name>

## Question

What mechanism or hypothesis is this experiment testing? State the prediction.

## Setup

Host/OS, kernel, CPU/GPU, memory, tool versions, compiler flags, dependencies, and input data.

## Procedure

Exact commands and inputs needed to reproduce the work.

## Results

Measurements, plots, test output, and the raw-data location.

## Interpretation

What happened, why, limitations, and the next experiment.
```

## Before you start

- Read the course file's lab section and required reading.
- Record the environment before the first measurement.
- Keep large data and generated artifacts out of Git.
- Work in an isolated, authorized environment for security labs.
