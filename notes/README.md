# Notes and Retrospectives

Create `notes/<track>/<course>/summary.md` at the end of each course. Keep it concise and evidence-led:

```markdown
# <course> summary

## Mental model

## Key terms I can explain

## Evidence from my lab

## Failure or misconception corrected

## Exit-check self-assessment

## References used
```

Record the edition/date of external materials and the hardware/software environment for every performance, ML, or security result.
