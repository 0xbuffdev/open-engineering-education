# Local Book Library

This directory is for **legal local copies only** (PDF/EPUB). It is intentionally ignored by Git except for this file.

- The tracked reading maps are in [curriculum/books/](../curriculum/books/README.md).
- Do not commit books, scans, paywalled chapters, or downloaded course material.
- Do not rely on page numbers from search results or a different edition; use the section titles in the maps.
- If a book is unavailable, record the blocker in `notes/<track>/<course>/resources.md` and use the alternative named in the course file.

The curriculum is designed to work without local books: every course names a legal primary source and an alternative.
